# Manajemen Tamu

Kelola daftar tamu undangan Anda dengan mudah. Di bagian ini, Anda akan mempelajari cara:

- **Menambah Tamu**: Masukkan data tamu secara manual atau sekaligus.
- **Grup Tamu**: Kelompokkan tamu berdasarkan kategori (misal: Keluarga, Teman Kantor).
- **Kirim Undangan**: Cara mengirimkan link undangan ke masing-masing tamu.
- **Pantau Kehadiran**: Pantau siapa saja yang sudah mengonfirmasi kehadiran.
